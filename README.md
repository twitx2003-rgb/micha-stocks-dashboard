# דשבורד מקומי: YouTube + TradingView

הפרויקט מריץ אתר מקומי שמושך סרטונים אחרונים מערוץ YouTube, מזהה סימולי מניות שמופיעים בכותרות, ומציג לכל סימול גרף חי של TradingView.

## הרצה

```powershell
npm start
```

לאחר מכן פותחים:

```text
http://localhost:4173
```

## כניסה מהטלפון

הטלפון והמחשב צריכים להיות על אותה רשת Wi‑Fi. כדי לראות את הכתובת לטלפון:

```powershell
npm run urls
```

לאחר מכן מפעילים את האתר:

```powershell
npm start
```

ופותחים בטלפון את הכתובת שמופיעה תחת `Phone URL`.

## צילומי מסך של TradingView

כדי ליצור צילומי מסך למניות הרלוונטיות מהערוץ ומרשימת המעקב:

```powershell
npm run capture
```

התמונות נשמרות בתיקייה `screenshots`.

## ניתוח טכני וצ׳ק ליסט דינמי

המערכת מושכת את הסרטונים האחרונים ומנסה לקרוא תמלולים/כתוביות ציבוריים. מניות נכנסות לרשימה לפי איכות ההקשר בתמלול, לא רק לפי כותרת או רשימת מעקב ידנית.

המערכת מחזיקה Universe אוטומטי של NASDAQ/NYSE מקבצי Nasdaq Trader:

- `nasdaqlisted.txt` עבור NASDAQ.
- `otherlisted.txt` עבור NYSE.
- כל סוגי הסימולים נכללים, למעט סימולי בדיקה.
- ה־Universe נשמר מקומית ב־`data/universe.json`.
- ה־Universe משמש לאימות מועמדים בלבד; הוא לא מוצג כולו בצ׳ק ליסט.

הצ׳ק ליסט אינו קבוע. רשימת המעקב הידנית היא מקור עזר בלבד, וברירת המחדל היא לא להכניס אותה אוטומטית לרשימה. לאחר שהניתוח הטכני נטען, הרשימה מסתננת לפי תנאי היום: מבנה ממוצעים, RSI, MACD, קרבה לפריצה, תמיכה/התנגדות ואיכות האזכור בתמלול.

אם הסרטונים והתמלולים נותנים מעט מדי סימולים ישירים, מופעלת הרחבת `marketScout`: המערכת מוסיפה מועמדות טכניות מתוך Universe רחב, מנתחת אותן, ומציגה רק את אלה שעוברות סף עניין טכני. כך הרשימה יכולה לגדול או להצטמצם לפי הצורך היומי.

באתר, בוחרים מניה והניתוח נטען אוטומטית. המערכת מציגה:

- גרף טכני פנימי עם מחיר, תמיכה, התנגדות, אזור פריצה וקו מגמה.
- RSI, MACD, ממוצע 20, ממוצע 50.
- הסבר למה המניה נכנסה לצ׳ק ליסט.
- טריגר פריצה ואזור ביטול/חולשה.
- תג `מניה חמה` כאשר כמה תנאים טכניים מסתדרים יחד.

הווידג׳ט הרשמי של TradingView לא מאפשר לצייר מתוכו קווי מגמה חופשיים דרך קוד חיצוני. לכן TradingView מציג גרף דינמי עם אינדיקטורים, והגרף הטכני הפנימי מצייר את קווי הניתוח: תמיכה, התנגדות, אזור פריצה וקו מגמה.

בנוסף קיימות שתי אוטומציות:

- `סיכום יומי Micha.Stocks` רצה בבוקר, בצהריים ובערב.
- `סריקת מניות חמות Micha.Stocks` רצה כל שלושה ימים ומחפשת מועמדות לפני פריצה אפשרית.

## סקילים שנוצרו

נוצרו שני סקילים אישיים:

- `tactile-web-designer`: מומחה עיצוב אתרים מוחשיים, נגישים ואינטראקטיביים.
- `elite-technical-chartist`: מומחה ניתוח טכני מתקדם, קווי מגמה, תמיכה/התנגדות, פריצות וצ׳ק ליסט.
- `dynamic-market-scout`: מומחה לבניית רשימות מניות דינמיות רחבות מתמלולים, Universe וסינון טכני.

## הגדרת ערוץ YouTube

באתר עצמו אפשר להזין `channelId` ולשמור. אפשר גם לערוך ידנית את `config.json`.

דוגמה:

```json
{
  "youtube": {
    "channelId": "UCxxxxxxxxxxxxxxxxxxxxxx",
    "channelUrl": ""
  },
  "watchlist": ["NASDAQ:NVDA", "NASDAQ:AAPL", "NASDAQ:MSFT"],
  "market": {
    "defaultExchange": "NASDAQ",
    "maxVideos": 12
  }
}
```

## מה עובד עכשיו

- משיכת סרטונים אחרונים דרך RSS ציבורי של YouTube.
- זיהוי סימולים מכותרות הסרטונים, למשל `$NVDA`, `NASDAQ:TSLA`, או `AAPL`.
- הצגת גרף TradingView חי לכל סימול.
- שמירת ערוץ ורשימת מעקב מקומית.

## מה צריך כדי להגיע לניתוח יומי מלא

כדי להפיק מסקנות טכניות אמיתיות בכל יום, צריך להוסיף לפחות אחד מאלה:

- תמלול/תקציר של הסרטונים, דרך YouTube Transcript או API חיצוני.
- מקור נתוני מחירים היסטוריים לחישוב אינדיקטורים כמו RSI, MACD, ממוצעים נעים, נפח ומגמה.
- אוטומציה יומית שתרוץ בשעה קבועה ותייצר סיכום.

המערכת הנוכחית היא בסיס מקומי טוב: היא כבר יודעת לאסוף מועמדים מהערוץ ולהציג אותם מול TradingView, בלי לתת “המלצת השקעה”.
